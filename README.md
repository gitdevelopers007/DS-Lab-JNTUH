# Data Structures Lab - JNTUH

This repository contains C implementations of various Data Structures and Algorithms as per the JNTUH syllabus. Each module is designed to be clear, modular, and easy to understand for academic purposes.

## 📁 Project Structure

The project is organized into subdirectories, each containing a modular C implementation:

- `singly_linked_list/`: Basic operations on SLL.
- `doubly_linked_list/`: Operations on DLL.
- `circular_linked_list/`: Operations on Circular Linked List.
- `stack/`: Stack implementation using Arrays and ADT.
- `queue/`: Queue implementation using Arrays and ADT.
- `sorting/`: Radix, Heap, Shell, and Tree Sort.
- `tree_traversals/`: Recursive and Non-recursive traversals.
- `trees/`: BST, AVL, RB, B-Tree, and B+ Tree (Simplified).
- `graphs/`: BFS and DFS algorithms.
- `hashing/`: 4 Hashing methods (Division, Multiplication, Mid-square, Folding).

## 🚀 How to Compile and Run

Each folder contains a `main.c`, `functions.c`, and `functions.h`. To run a specific program, navigate to its directory and use:

```bash
gcc main.c functions.c -o output
./output
```

## 📜 Requirements
- GCC Compiler (MinGW for Windows or build-essential for Linux).
- Standard C99 or later.
